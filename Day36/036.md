Day 36 of 100 Days of DevOps challenge on KodeKloud.

The Nautilus DevOps team was conducting application deployment tests on selected application servers. As part of the task, I created a container named nginx_3 on Application Server 3 using the nginx:alpine image and ensured that the container was running successfully.

Nginx is a widely used web server and reverse proxy that can also be deployed as a containerized application. Using the Alpine-based image provides a lightweight environment, making it useful for containerized deployments where a smaller image footprint is preferred.

Good to Know?

Docker Run Options
-d: Detached mode (run in background)
--name: Assign custom name to container
-p: Port mapping (host:container)
-v: Volume mounting for persistent data

NGINX Alpine
Alpine Linux: Minimal Linux distribution (~5MB)
Security: Reduced attack surface
Performance: Faster startup and lower resource usage
Production: Ideal for production deployments

Container Management
List: docker ps (running), docker ps -a (all)
Stop: docker stop container-name
Start: docker start container-name
Remove: docker rm container-name
