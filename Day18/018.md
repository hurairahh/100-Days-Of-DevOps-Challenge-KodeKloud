Day 18 of 100 Days of DevOps challenge on KodeKloud focused on MariaDB database administration and configuration.

The task involved setting up a MariaDB database server in the Nautilus infrastructure, creating a database named kodekloud_db6, and creating a dedicated database user with the required credentials. I then granted the user full privileges on the database to ensure it could perform the necessary operations for the application.

-- SQL Commands used in the task

CREATE DATABASE kodekloud_db6;

CREATE USER 'kodekloud_aim'@'localhost'
IDENTIFIED BY 'LQfKeWWxWD';

GRANT ALL PRIVILEGES ON kodekloud_db6.* 
TO 'kodekloud_aim'@'localhost';

FLUSH PRIVILEGES;
